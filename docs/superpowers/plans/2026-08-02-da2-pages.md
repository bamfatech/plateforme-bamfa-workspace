# DA-2 (pages) — Assemblage éditorial des pages publiques « La Revue » : Plan d'implémentation

> **Auteur** : Charlot DEDINOU
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Réf. direction artistique** : [../specs/2026-08-02-refonte-direction-artistique-design.md](../specs/2026-08-02-refonte-direction-artistique-design.md) · **Composants** : [DA-2 composants](./2026-08-02-da2-composants.md)

**Goal:** Assembler les 3 pages publiques (Accueil, À propos, Contact) dans le langage éditorial : rythme des fonds papier + filets, séparateurs `FlameGlyph`, révélations `Reveal` par section, nav d'ancres éditoriale, et refonte du bloc Contact (suppression du panneau dégradé).

**Architecture:** On introduit un composant `SectionDivider` (fleuron `FlameGlyph` entre filets) puis on réécrit les 3 pages : suppression de `bg-cream` (base papier), enveloppes `Reveal` sur les blocs, séparateurs entre sections majeures, cartes « fonctionnement » et logos partenaires en éditorial, nav d'ancres en mono, et bloc Contact refondu (coordonnées en liste typographique + formulaire, plus de dégradé). Le formulaire de contact (`ContactForm`) voit son `textarea`/label passés en éditorial (le reste réutilise `Field`, déjà éditorial).

**Tech Stack:** Next.js 15 (App Router, Server Components consommant des Client Components), React 19, Tailwind v4, `Reveal`/`FlameGlyph` (DA-1), composants de sections (DA-2 composants), Vitest + Testing Library.

## Global Constraints

- **Langue** : UI/contenu et **messages de commit** en **français**. Ne **jamais** mentionner Claude/IA/assistant. Commits `feat:`.
- **Dépôt** : `frontend/` uniquement. Alias `@/*`.
- **Tokens éditoriaux (DA-1)** : `ink`, `paper`, `flame` (marques/filets, non-texte), `flame-ink` (accent **texte** AA), `ember`, `gold`, `stone-300` (filets), `stone-600` (texte 2ndaire). Police display = `font-heading` (Fraunces), utilité = `font-mono`.
- **Discipline** : base **papier** (retirer `bg-cream`), **filets** `stone-300`, rayons **nets** (`rounded-sm`), pas de `bg-brand-gradient` (réservé logo). Accent **texte** = `flame-ink`.
- **Contenu inchangé** : on ne modifie pas les fichiers `content/*.ts` ; on ne fait que réagencer/reclasser le rendu des pages (les textes restent identiques).
- **Tests de pages protégés** : `app/(public)/page.test.tsx` (Accueil : h1 `/alumni Mastercard Foundation/i` + texte `250+`) et `app/(public)/about.test.tsx` (h1 `À propos de BAMFA`, `Solidarité`, heading `Gouvernance`, `Mandat 2024-2026`, `Président(e)`, `Qui peut devenir membre`) doivent **rester verts** — garder tous ces textes/headings.
- **`Reveal` en page (Server Component)** : `Reveal` est un Client Component ; l'envelopper autour de contenus rendus côté serveur est valide (les enfants server sont passés en props). Ne pas rendre les pages `"use client"`.
- **Accessibilité** : contrastes AA, focus visibles, `Reveal` honore `prefers-reduced-motion`.
- **Plateforme Windows** : si `npm run build` échoue sur un cache périmé, `rm -rf .next` puis rebâtir.
